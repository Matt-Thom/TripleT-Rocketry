# ADR: Impulse Class Safety

**Status:** Accepted (2026-07-20)

**Context**

Per T-1 research ([[queries/rocketry-domain-research]]), NAR/TRA motor impulse classes A–O are defined by total impulse (N·s) ranges that double at each step. Standard model rocketry (NFPA 1122) covers up to G; high-power rocketry (HPR, NFPA 1127) begins at H. NAR/TRA certification levels map as Level 1 (H–I), Level 2 (J–L), and Level 3 (M–O).

**Decision**

Embed the following impulse class table as an immutable reference (enum + lookup) in the `Motor` entity. The `Certification` entity records user level. `Flight` and pre-flight checks implement soft-gates driven by `Motor.impulse_class` + `Certification.level`.

| Class | Total Impulse (N·s) | Certification |
|-------|---------------------|---------------|
| A     | 1.26–2.50           | -             |
| B     | 2.51–5.00           | -             |
| C     | 5.01–10.0           | -             |
| D     | 10.01–20.0          | -             |
| E     | 20.01–40.0          | -             |
| F     | 40.01–80.0          | -             |
| G     | 80.01–160           | -             |
| H     | 160.01–320          | Level 1       |
| I     | 320.01–640          | Level 1       |
| J     | 640.01–1,280        | Level 2       |
| K     | 1,280.01–2,560      | Level 2       |
| L     | 2,560.01–5,120      | Level 2       |
| M     | 5,120.01–10,240     | Level 3       |
| N     | 10,240.01–20,480    | Level 3       |
| O     | 20,480.01–40,960    | Level 3       |

Motors ≤ G are “model rocket” (NFPA 1122); motors ≥ H are “high-power rocket” (NFPA 1127) and require the corresponding certification level plus range-safety oversight. No hard regulatory engine in MVP—warnings + audit trail only. Prefer Composite Alloy (e.g. COMP-MOTOR-SAFETY) for checks.
